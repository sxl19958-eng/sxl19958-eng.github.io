# Xiaoli Su · Academic Homepage

This is a **standalone, independent** academic website for **Xiaoli Su (苏晓丽)**. It is not a subsite of Bo Shao and does not inherit his research, biography, tracking codes, or account settings.

## Quick deployment (GitHub Pages)

1. Create a **new** GitHub repository under Xiaoli Su's own GitHub account, ideally `<her-github-username>.github.io`.
2. Upload the **contents of this folder** to the root of that repository (keep `index.html` in the root).
3. Under **Settings > Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. After GitHub Pages publishes, check navigation, DOI links, the PDF download, and the portrait.

Alternatively, a repository with any name (e.g., `academic-homepage`) can be published as a GitHub Pages project website. All navigation links and asset paths here are relative and support this option.
